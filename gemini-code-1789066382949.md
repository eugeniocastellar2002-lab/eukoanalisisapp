# ⚽ Terminal de Análisis Estadístico Cuantitativo — Tipster Pro

Aplicación web desarrollada en **Python** con **Streamlit** diseñada para el análisis cuantitativo de fútbol, modelación estadística para apuestas deportivas y detección de valor (+EV).

## 🚀 Funcionalidades

- **📊 Estadística Descriptiva Avanzada:** Recuento, promedio, desviación estándar, coeficiente de variación, mínimos, máximos y sesgo estandarizado.
- **🎲 Modelo de Poisson Bivariado:** Matriz interactiva de marcadores exactos y estimación de probabilidades de victoria/empate.
- **📈 Regresión Lineal & ANOVA:** Correlación de variables (tiros, córneres, faltas) frente a goles o tarjetas con tabla de varianza.
- **🔔 Distribución Normal:** Estimación de probabilidad para líneas de hándicap y overs/unders.
- **💰 Calculadora +EV & Stake (Kelly):** Evaluación del valor esperado y gestión de banca mediante el Criterio de Kelly (Fraccionado).
- **📁 Carga de Datos:** Compatibilidad con archivos Excel (.xlsx) y CSV o uso de datos preseteados.

## 🛠️ Tecnologías

- Python 3.10+
- Streamlit
- Pandas & NumPy
- SciPy & Statsmodels
- Plotly Express
